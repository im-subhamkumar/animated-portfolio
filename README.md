## 🌟 Overview

A high-performance, cinematic personal portfolio designed and engineered with modern web animation principles. Features interactive scroll-scrubbed canvas rendering, dynamic custom cursor physics, smooth GSAP-driven transitions, and responsive dark-mode aesthetics.

Built to showcase end-to-end full-stack architectures, agentic AI pipelines, and production-ready applications.

## 💻 Getting Started Locally

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (version 18 or higher recommended).

### 1. Clone the repository
```bash
git clone https://github.com/im-subhamkumar/animated-portfolio.git
cd animated-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

### 4. Build for production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.

### 5. Preview production build
```bash
npm run preview
```
